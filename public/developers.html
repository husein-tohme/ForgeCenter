Developer API

Use ForgeCenter from your own code: chat with Claude in your Discord bot or game, make mods, texture packs and plugins, and search Modrinth. There's nothing to buy up front. Each call is paid from your ForgeCenter wallet, and you only pay for calls that work.

  1. Make a keyIt takes a second, and you can have up to 5. Keys are for confirmed adults (18+).
  2. Add fundsTop up your wallet by card. The money is there straight away.
  3. Call the APISend your key with each request. The cost comes out of your wallet as you go.

    Endpoints

    Every request goes to https://YOUR-DOMAIN/v1 with your key in the Authorization header. Send bodies as JSON. Keep your key in an environment variable, not in your code:

    export FORGECENTER_KEY="paste your key here"
    POST/v1/chatChat with Claude

    Send the conversation so far and get Claude's reply. The model is Claude Opus 5.5. Costs per token.

    • messages (required): a list of { "role": "user" | "assistant", "content": "text" } turns, starting and ending with the user. Up to 100.
    • system: your instructions for Claude, up to 8,000 characters. ForgeCenter adds a short note of its own before them.
    • max_tokens: the longest reply you'll pay for, from 1 to 4,096. Default 1,024.
    • effort: "low" (default), "medium" or "high". Higher effort thinks more first, which uses more of max_tokens.
    curl https://YOUR-DOMAIN/v1/chat \
  -H "Authorization: Bearer $FORGECENTER_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "system": "You help players plan Minecraft builds.",
    "messages": [{ "role": "user", "content": "Ideas for a desert base?" }],
    "max_tokens": 800
  }'

    The answer, with what the call cost and what's left in your wallet (both in cents):

    {
  "reply": "Here are a few ideas…",
  "stop_reason": "end_turn",
  "usage": { "input_tokens": 61, "output_tokens": 412 },
  "cost_cents": 2,
  "balance": 1498
}

    From JavaScript, for example in a Discord bot (Node 18 or newer):

    const r = await fetch("https://YOUR-DOMAIN/v1/chat", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.FORGECENTER_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({ messages: [{ role: "user", content: "Name ideas for a pet dragon?" }] }),
});
const data = await r.json();
if (!r.ok) throw new Error(data.error);
console.log(data.reply);

    Before the call, your wallet needs enough for the longest possible answer. You're charged only for what was used. If stop_reason is "max_tokens", the answer was cut short, so ask again with a higher max_tokens.

    POST/v1/modsMake a Fabric mod

    Returns a zip with a ready-to-build Fabric mod project, the same as Mod Forge. Costs a cent.

    • name, author and description (required).
    • items: names of items to add. mcVersion: the Minecraft version, default 1.21.1. license: default MIT.
    curl https://YOUR-DOMAIN/v1/mods \
  -H "Authorization: Bearer $FORGECENTER_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "name": "Ruby Mod", "author": "Steve", "description": "Adds rubies", "items": ["Ruby", "Ruby Block"] }' \
  -o ruby-mod.zip
    POST/v1/pluginsMake a server plugin

    Returns a zip with a Paper plugin project, the same as Plugin Forge. Costs a cent.

    • name, author and gameVersion (required): 1.21.8, 1.21.4, 1.21.1, 1.20.6 or 1.20.4.
    • commands: up to 10 { "name", "reply" } pairs. welcome, announcements (one per line) and announceEvery (minutes). {player} becomes the player's name.
    curl https://YOUR-DOMAIN/v1/plugins \
  -H "Authorization: Bearer $FORGECENTER_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "name": "Hello World", "author": "Steve", "gameVersion": "1.21.8",
        "commands": [{ "name": "rules", "reply": "<gold>Be kind and have fun!" }],
        "welcome": "<green>Welcome, {player}!" }' \
  -o hello-world.zip
    POST/v1/texturepacksMake a resource pack

    Returns a resource pack zip, the same as Texture Forge. Costs a cent.

    • gameVersion (required), name and description.
    • textures (required): up to 40 { "target", "png" }, where png is a 16 by 16 PNG as a data URL. The targets you can replace are listed at /api/texturepack/options.
    curl https://YOUR-DOMAIN/v1/texturepacks \
  -H "Authorization: Bearer $FORGECENTER_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "name": "Ruby Pack", "gameVersion": "1.21.8",
        "textures": [{ "target": "item/diamond", "png": "data:image/png;base64,iVBORw0KGgo…" }] }' \
  -o ruby-pack.zip
    GET/v1/modrinth/searchSearch Modrinth

    Finds Fabric mods or server plugins on Modrinth. Costs a cent.

    • q: what to search for. kind: mod (default) or plugin. version: a Minecraft version, default the newest.
    curl "https://YOUR-DOMAIN/v1/modrinth/search?q=sodium&kind=mod&version=1.21.8" \
  -H "Authorization: Bearer $FORGECENTER_KEY"
    GET/v1/meCheck your key

    Shows the key's name, your account name and your wallet balance in cents. Free.

    curl https://YOUR-DOMAIN/v1/me -H "Authorization: Bearer $FORGECENTER_KEY"

    Limits and errors

    Each key can make 60 requests a minute, with up to 2 running at once. Errors come back as JSON, like { "error": "What went wrong and what to do" }.

    400
    Something in the request is missing or wrong. The error says what.
    401
    The key is missing, mistyped or revoked.
    402
    Your wallet can't cover the call. Add funds, or ask for a shorter answer.
    403
    The key's account isn't confirmed as an adult.
    415
    The body wasn't sent as JSON.
    422
    Claude declined the request. You weren't charged.
    429
    Too many requests. Wait for the seconds in the Retry-After header, or for a running request to finish.
    502
    Claude or Modrinth didn't answer. You weren't charged, so try again.
    503
    AI chat isn't switched on for this site right now.

    Rules for API keys

    • Keep your key secret. Use it from your server or bot, never in a web page or an app you give to other people. If it leaks, revoke it here and make a new one.
    • You're responsible for what your key does. Follow the ForgeCenter terms and Anthropic's usage policy. Don't use the API to harm, trick or spam people.
    • If your app has users, tell them it uses AI, and don't send their personal details unless you need to.
    • Charges come from your wallet, which can't be withdrawn. If a charge looks wrong, open a ticket.
