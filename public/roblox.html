Roblox Forge

Make the start of your own Roblox game. Pick a template, give it a name and choose some extras. You'll download a project you open in Roblox Studio, with saving already built in. It's free and you don't need an account.

Game template

The currency shows on the leaderboard. Use letters, numbers and spaces.

Numbers

Leave a box empty to use the suggested number. You can change all of these later in Config.lua.

Extras

You'll get a zip with Luau scripts and a Rojo project file. Signed in? It's also saved to your account.

Open it in Roblox Studio

      
    
        
  1. Install Rojo from rojo.space. With Rokit or Aftman, run rokit install or aftman install in the project folder. Then add the Rojo plugin to Studio with rojo plugin install.
    2. 
        
  2. Unzip the project and run rojo serve in its folder.
    3. 
        
  3. Connect from Studio. Open a Baseplate, open the Rojo plugin and press Connect. Your scripts appear straight away.
    4. 
        
  4. Turn on saving. Publish the place once, then in Game Settings, Security, switch on "Enable Studio Access to API Services" so DataStores work while you test.
    5. 
        
  5. Press Play to try it, and use File, Publish to Roblox when it's ready.
    6. 
      

      
The README in the zip has the same steps and explains every file. Roblox Forge isn't made by or affiliated with Roblox Corporation.
