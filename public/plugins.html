Plugin Forge

Make your own plugin for a Paper or Purpur server: commands that reply with your messages, a welcome message, and announcements on a timer. Everything it says can be changed later in its config file.

Commands

Each command replies with your message. Colours use tags like <green>, <gold> or <bold>, and {player} becomes the player's name.

You'll get a Java project. The included README shows how to build it into a jar with IntelliJ IDEA or Gradle.
