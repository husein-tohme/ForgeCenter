Sign-in setup

Turn on ways for people to sign in. GitHub takes one click; the others need a few minutes in each company's developer site.

Enter your setup code

Nobody can sign in yet, so this page is unlocked with a one-time code from the server log. On Render: open your service, then Logs, and look for Sign-in setup code.

GitHub

Checking…

GitHub opens with the app already filled in. Press the green Create GitHub App button there and you'll come straight back here. Nothing to copy.

Google, Discord and Microsoft

These companies don't allow one-click setup, so each needs a free app made in their developer site (about 5 minutes each). Paste the keys into your host's environment settings:

  • Google: Google Cloud credentials, OAuth client ID, Web application, add your site under Authorized JavaScript origins. Set GOOGLE_CLIENT_ID.
  • Discord: Discord developer portal, New Application, OAuth2, add the redirect . Set DISCORD_CLIENT_ID and DISCORD_CLIENT_SECRET.
  • Microsoft: App registrations, New registration, any account type, Web redirect . Set MICROSOFT_CLIENT_ID and MICROSOFT_CLIENT_SECRET.
