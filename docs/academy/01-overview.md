# 1. Overview

## What it is

A coding school in one site. Students watch the best videos on each topic, see exactly which code each moment explains, ask an AI tutor when they're stuck, and build real projects that go live: websites, Discord bots, Minecraft mods, Roblox games, all the way up to their own operating system.

It teaches everyone, from total beginners to professional developers, in 24 core languages and 20 more, and it's cheap: $1 for the first month, $5 a month after, and free for verified students.

## Who it's for

- **Just started:** never coded before, often young. Starts with Python, or Scratch once it arrives in wave 2.
- **Hobby coder:** knows the basics and wants to build things like bots, mods and apps.
- **Professional:** works or wants to work as a developer. Wants AI, security, system design and job prep.
- **Teachers and schools:** run classes on it and track their students.

## The five things nobody else has together

1. **Video synced to real code.** Click a line and see the clip that explains it; watch a clip and its code lights up.
2. **An AI tutor that knows where you are** in the lesson and the code.
3. **Projects that go live** and can be shown to friends.
4. **The Context Switcher:** the same idea side by side in Python, C++ and Assembly.
5. **The price:** $1 first month, free for students.

## Principles

- **Never overwhelming.** One clear next step, always. The site is huge, but each screen is simple.
- **Build something in the first hour.**
- **Fair to creators.** Their names, channels and views stay theirs.
- **Safe for kids.** Strict message rules, moderation, and no ID photos or card numbers stored.
- **Legal by design.** YouTube videos are embedded, never downloaded.
- **Fast on slow internet and phones**, because many students (in Lebanon and elsewhere) are on weak connections.
