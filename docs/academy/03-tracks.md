# 3. Tracks and languages

Students learn by building. The basics (variables, loops, functions) are taught inside projects, not as separate drills, so nobody quits before building something.

## Levels

1. **Beginner:** Scratch, Python, first websites, loops and the basics
2. **Hobby coder:** Discord bots, Minecraft texture packs, plugins and mods, apps, sign-in systems, forms
3. **Professional:** AI, a search engine, Claude plugins, cybersecurity, cloud, system design
4. **Expert:** an operating system, a Minecraft server from scratch, your own language, a game engine, an emulator, a database

Expert tracks unlock after the basics they need (for example, C before building an OS).

## The 24 core languages

| Group | Languages | What students build |
|---|---|---|
| Start here | Scratch, Python | Simple games and animations, then real programs |
| Websites | HTML, CSS, JavaScript, TypeScript, React, PHP | Personal sites, online stores, web apps |
| Games | Luau (Roblox), C#, C++ | Roblox games, Unity games, game engines |
| Apps | Swift, Kotlin, Java | iPhone apps, Android apps, Minecraft mods |
| Backend and servers | Go, Ruby, Elixir, Rust | APIs, chat servers, Discord bots |
| Data | SQL, R | Databases, charts, data analysis |
| Low-level | C, C++, Assembly, Rust | How computers really work, fast programs, security |
| Functional | Haskell, F#, Elixir | A different way of thinking about code |

Notes:

- React is a JavaScript library, so it comes at the end of the website track, after JavaScript.
- Scratch uses drag-and-drop blocks, so its lessons need a block editor instead of a code editor.
- Luau ties into ForgeCenter's Roblox Forge.
- Swift works best on a Mac for iPhone apps; tell students up front.

### Order the languages are added

3. Wave 3: TypeScript, React, PHP, C, C++, Kotlin, Swift

## How tracks connect

- The basics
  - Websites → sign-in systems → forms and payments → search engine
  - Minecraft: texture packs → plugins → mods → run a server → server from scratch
  - Discord bots → Claude plugins → automation and webhooks
  - Apps and installers
  - AI → make your own AI → AI research
  - C → Assembly → make your own OS

ForgeCenter's free tools (Mod Forge, Texture Forge, Plugin Forge, AI Maker, Roblox Forge) are the "try it first" step: students make something with the tool, then learn to build it from scratch.
