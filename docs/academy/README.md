# The coding academy plan

The plan for ForgeCenter's learning site: video lessons synced to real code, an AI tutor, and tracks for 23 languages, from Scratch to building an operating system. The name isn't decided yet; "the Academy" is a placeholder.

This folder is the plan. No code gets written until the plan is finished.

## How "start" and "continue" work

When the owner says **continue**, do the first unchecked step below, update the documents, tick the step, commit and push, then say in a few lines what was done and what's next.

- [x] Write documents 1, 2, 3 and 5 from the decisions made in chat, and Block 1 in document 4
- [x] Block 2: the learning screen (video, code and map together; Context Switcher; starting quiz; docs pages)
- [ ] Block 3: sandboxes (Discord bots, code playground, hacking labs, OS lessons)
- [ ] Block 4: content (finding, rating and checking 2 million links; uploads; moderation)
- [ ] Accounts and roles in detail (sign-in, roles, inboxes and message safety)
- [ ] Document 6: the roadmap, with risks for each phase
- [ ] Final check: read every document for gaps and contradictions, and ask the owner about anything still open (the name first)
- [ ] Then, and only then, start building, beginning with the launch features in document 2
