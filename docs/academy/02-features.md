# 2. Features

Everything the owner agreed to in planning, sorted by when it ships:

- **Launch:** in the first version
- **Soon:** in the first few months after launch
- **Later:** once the site is growing

Every feature is in the plan; the sorting only decides the order. The home page shows the top five, a features page lists everything, and a "Coming soon" page lists the later ones without dates.

Message safety rules (not optional):

- Under 18: messages only with accepted friends, their teachers and classmates. No strangers.
- Adults can't message minors they don't know.
- The AI scans for scams, bullying and inappropriate messages, and anyone can report a message.
- Block and mute everywhere.
